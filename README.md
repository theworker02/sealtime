# sealtime

Seal encode/decode helpers for time payloads in pipelines.

**Site:** https://theworker02.github.io/sealtime/

## Install / run

```bash
git clone https://github.com/theworker02/sealtime.git
cd sealtime
node src/cli.js
node --test
```
